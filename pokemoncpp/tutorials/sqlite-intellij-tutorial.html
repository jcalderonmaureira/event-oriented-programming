Cómo crear el archivo .db de SQLite
💡 SQLite no necesita instalación de servidor. El archivo .db es la base de datos completa. Elige la opción que mejor se adapte a tu flujo de trabajo.
⭐
Opción 1 — Automático al ejecutar el código (recomendado)
Más fácil ▶

JDBC crea el archivo .db automáticamente la primera vez que te conectas, si no existe. Solo necesitas crear la carpeta data/ manualmente:

Click derecho en el proyecto
→
New → Directory
→
Escribe: data

Luego, al ejecutar tu Main.java con esta línea, el archivo se crea solo:

JAVA 
// Crea data/myapp.db automáticamente si no existe
Connection conn = DriverManager.getConnection(
    "jdbc:sqlite:data/myapp.db"
);
✅ Esta es la opción más recomendable para proyectos nuevos. El proceso queda reproducible para cualquier desarrollador que clone el repositorio.

ℹ️ También puedes arrastrar y soltar un archivo .db existente directamente al panel Database para conectarlo al instante.
3
Opción 3 — Desde la Terminal integrada
Manual ▶

Abre la terminal de IntelliJ con Alt+F12 y ejecuta según tu sistema:

LINUX / MAC 
# Crea la carpeta y el archivo vacío
mkdir -p data && touch data/myapp.db
WINDOWS (PowerShell) 
New-Item -ItemType Directory -Force data
New-Item -ItemType File data\myapp.db
⚠️ Un archivo creado con touch está vacío (0 bytes). SQLite lo inicializará correctamente la primera vez que tu código escriba datos en él.
4
Opción 4 — Con el cliente sqlite3 en terminal
Avanzado ▶

Si tienes sqlite3 instalado en tu sistema, puedes crear y poblar la base de datos directamente:

SHELL

# Dentro del CLI, crea una tabla de prueba:

    nombre TEXT NOT NULL

# Verifica que se creó:
.tables

# Salir
.quit
💡 Instalar sqlite3: macOS → brew install sqlite | Ubuntu → sudo apt install sqlite3 | Windows → descarga desde sqlite.org/download

Implementación Java — CRUD completo
1
DatabaseManager — Conexión y esquema
Requerido ▶
JAVA 
import java.sql.*;

public class DatabaseManager {

    private static final String DB_URL =
        "jdbc:sqlite:data/myapp.db";

    private static Connection connection;

    public static Connection getConnection()
            throws SQLException {
        if (connection == null || connection.isClosed()) {
            connection = DriverManager.getConnection(DB_URL);
        }
        return connection;
    }

    public static void initializeSchema()
            throws SQLException {
        String sql = """
            CREATE TABLE IF NOT EXISTS usuarios (
                id      INTEGER PRIMARY KEY AUTOINCREMENT,
                nombre  TEXT    NOT NULL,
                email   TEXT    UNIQUE NOT NULL,
                activo  INTEGER DEFAULT 1,
                creado  TEXT    DEFAULT (datetime('now'))
            )
            """;
        try (Connection conn = getConnection();
             Statement stmt = conn.createStatement()) {
            stmt.execute(sql);
        }
    }
}
2
UsuarioDAO — Create, Read, Update, Delete
Requerido ▶
JAVA 
import java.sql.*;
import java.util.*;

public class UsuarioDAO {

    // CREATE
    public void insertar(String nombre, String email)
            throws SQLException {
        String sql = "INSERT INTO usuarios (nombre, email) VALUES (?, ?)";
        try (Connection conn = DatabaseManager.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, nombre);
            ps.setString(2, email);
            ps.executeUpdate();
        }
    }

    // READ ALL
    public List<String[]> listar() throws SQLException {
        List<String[]> lista = new ArrayList<>();
        String sql = "SELECT id,nombre,email FROM usuarios WHERE activo=1";
        try (Connection conn = DatabaseManager.getConnection();
             Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {
            while (rs.next()) {
                lista.add(new String[]{
                    rs.getString("id"),
                    rs.getString("nombre"),
                    rs.getString("email")
                });
            }
        }
        return lista;
    }

    // UPDATE
    public void actualizar(int id, String nombre)
            throws SQLException {
        String sql = "UPDATE usuarios SET nombre=? WHERE id=?";
        try (Connection conn = DatabaseManager.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, nombre);
            ps.setInt(2, id);
            ps.executeUpdate();
        }
    }

    // DELETE (soft delete recomendado)
    public void eliminar(int id) throws SQLException {
        String sql = "UPDATE usuarios SET activo=0 WHERE id=?";
        try (Connection conn = DatabaseManager.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, id);
            ps.executeUpdate();
        }
    }
}
3
Main — Punto de entrada
Requerido ▶
JAVA 
public class Main {
    public static void main(String[] args) {
        try {
            // 1. Crear tablas si no existen
            DatabaseManager.initializeSchema();

            UsuarioDAO dao = new UsuarioDAO();

            // 2. Insertar
            dao.insertar("Ana López",    "ana@ejemplo.cl");
            dao.insertar("Carlos Ruiz", "carlos@ejemplo.cl");

            // 3. Listar
            dao.listar().forEach(u ->
                System.out.printf("[%s] %s — %s%n",
                    u[0], u[1], u[2]));

            // 4. Actualizar
            dao.actualizar(1, "Ana María López");

            // 5. Soft-delete
            dao.eliminar(2);

        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

Buenas prácticas
🛡️
Siempre usar PreparedStatement (anti SQL Injection)
Seguridad ▶
JAVA 
// ❌ NUNCA — vulnerable a SQL Injection
String sql = "SELECT * FROM usuarios WHERE nombre = '"
           + nombre + "'";

// ✅ SIEMPRE usar PreparedStatement
String sql = "SELECT * FROM usuarios WHERE nombre = ?";
PreparedStatement ps = conn.prepareStatement(sql);
ps.setString(1, nombre);
⚡
Transacciones para operaciones múltiples
Importante ▶
JAVA 
public void operacionMultiple() throws SQLException {
    Connection conn = DatabaseManager.getConnection();
    try {
        conn.setAutoCommit(false); // inicio transacción

        // ... múltiples INSERT / UPDATE ...

        conn.commit(); // confirmar todo
    } catch (SQLException e) {
        conn.rollback(); // revertir si falla alguno
        throw e;
    } finally {
        conn.setAutoCommit(true);
    }
}
